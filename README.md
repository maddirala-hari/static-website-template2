# Static Website Template

## Project Overview
A responsive static website template prepared for practicing AWS cloud hosting and content delivery using Amazon S3 and Amazon CloudFront.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Amazon S3
- Amazon CloudFront

## Project Structure
- `index.html` — Main website page
- `timer.html` — Additional webpage
- `images/` — Website images and assets
- `tooplate-2167-orbital-script.js` — JavaScript functionality
- `tooplate-2167-orbital-style.css` — Website styling

## AWS Deployment Plan
1. Upload the static website files to an Amazon S3 bucket.
2. Configure website hosting and the required access permissions.
3. Set up Amazon CloudFront to deliver website content.
4. Test website accessibility and content delivery.
5. Review deployment configuration and troubleshoot errors.

## Learning Objectives
- Understand static website hosting.
- Practice S3 bucket configuration and file uploads.
- Learn CloudFront distribution basics.
- Develop AWS deployment and troubleshooting skills.

## Status
Prepared for AWS deployment practice. Deployment steps will be documented as they are completed.
